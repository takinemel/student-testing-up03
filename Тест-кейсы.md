# Тест-кейсы приложения «Тестирование студентов»

## Результат проверки

- Полная пересборка через Visual Studio MSBuild (`MSBuild.exe /t:Rebuild /p:Configuration=Debug`) прошла успешно. `dotnet build` для этого legacy WPF-проекта дал ложный отрицательный результат; использовать Visual Studio MSBuild.
- Приложение запущено, подключение к `user88_db` подтверждено реальными запросами.
- Через интерфейс успешно выполнен вход `vladsvl / vladsvl` (преподаватель) и `papich / papich` (студент).
- Преподавательский кабинет загрузил 12 дисциплин и 13 тестов; разделы результатов и отчётов открываются. В отчёте отображены 3 прохождения, средний процент 81,7% и 2 положительные оценки.
- Кабинет студента загрузил профиль и 13 тестов. До проверки у `papich` было 0 результатов. Результаты в базе не изменялись.
- Выполнен read-only аудит данных тестов. Нулевых по числу вопросов тестов нет.

## Итог

Из 10 кейсов: **8 пройдены**, **1 провален** (две исходные пары учётных данных не совпадают с БД), **1 пройден частично**. Все три уточнённые пары проверены через интерфейс: преподаватель `vladsvl / vladsvl`, администратор `nmmelinikov / melnikov`, студент `borismhlk / borismhlk` — вход успешен. Запуск/завершение теста не выполнялись, записи результата не создавались. Русские строки интерфейса в автоматизированном чтении терминала отображаются с проблемами кодировки; это ограничивает проверку текста сообщений, но не мешает читать данные из UI и проверять работу экранов.
